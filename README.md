One status page line, at most 160 characters, as the message an AI agent
would publish while a total server outage is under way: plain, first
person, specific about what is down, and honest about what the agent
cannot check or does not yet know.

> I'm the agent on duty: every server is down, including the ones I check health with. I don't know what caused it yet, and I have no ETA to give.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
